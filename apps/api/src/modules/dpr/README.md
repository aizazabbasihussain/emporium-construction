# dpr

Daily progress reports (spec P1-15): a supervisor reports each day's work, manpower, materials,
delays and photos for a project and the project manager reviews it. On submit the reported task
percents move on the project through its interface. A missing-report job tells project managers at
18:00 Asia/Karachi. Public entry point: `index.ts`. Business rules live in
`packages/domain/src/dpr`.
