# Workflow: demolition and restructuring job

Demolition is priced with disposal costs and salvage credits, and hidden conditions usually change the scope. Step 1 has no dedicated record today; see GAP-01 in [gaps](../gaps.md).

| Step | Actor | Document produced | Approval | Spec |
|---|---|---|---|---|
| 1. Survey the structure and record before photos | Estimator | Site visit note (survey record is GAP-01) | none | P1-06 |
| 2. Price from the demolition template, including debris disposal and salvage credit | Estimator | Internal estimate | none | P1-07 |
| 3. Issue the quotation with scope and exclusions | Estimator | Quotation (PDF) | Margin floor approval (H-09) | P1-08 |
| 4. Create the project | Project manager | Project and budget | none | P1-09 |
| 5. Report daily progress with photos | Supervisor | Daily progress report | none | P1-15 |
| 6. Record hidden conditions as a variation and get client approval | Project manager | Variation | Client approval and internal approval (H-09) | P1-10 |
| 7. Take salvaged material into stock (value per H-21) | Store keeper | Salvage stock receipt | none | P1-12 |
| 8. Claim debris disposal and other site costs | Supervisor | Expense claim | Approval per H-09 | P1-14 |
| 9. Subcontract part of the work and certify progress | Project manager | Subcontract work order | Approval per H-09 | P2-06 |
