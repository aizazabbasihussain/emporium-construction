# Workflow: paid maintenance job

Maintenance is a secondary, paid service that reuses customers, stock, labour and billing. Warranty jobs are flagged as non-billable.

| Step | Actor | Document produced | Approval | Spec |
|---|---|---|---|---|
| 1. Enter the request received by phone or WhatsApp | Office staff | Service request | none | P3-01 |
| 2. Check warranty and triage priority | Office staff | Triaged request | none | P3-01 |
| 3. Quote the work (fixed price or time and materials) and get acceptance | Estimator | Service quotation | Approval per H-09 | P3-04 |
| 4. Create the work order, assign a team and schedule it | Project manager | Work order | none | P3-02 |
| 5. Issue parts from the store to the work order | Store keeper | Stock issue to work order | none | P3-03 |
| 6. Charge labour through attendance | Supervisor | Attendance sheet | none (approved later) | P3-02 |
| 7. Record before and after photos and customer sign-off | Supervisor | Customer sign-off | none | P3-02 |
| 8. Invoice the completed, signed-off work order | Accountant | Service invoice | Approval per H-09 | P3-04 |
| 9. Review open jobs, turnaround, job profit and repeat visits | Owner | Maintenance reports | none | P3-05 |
