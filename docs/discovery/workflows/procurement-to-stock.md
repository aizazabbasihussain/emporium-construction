# Workflow: procurement to stock

Buying material, receiving it, holding it as company-owned or client-owned stock, and issuing it to a project.

| Step | Actor | Document produced | Approval | Spec |
|---|---|---|---|---|
| 1. Request material for a project | Supervisor or project manager | Requisition | Approval per H-09 | P1-11 |
| 2. Collect and compare vendor quotes | Procurement officer | Quote comparison | none | P1-11 |
| 3. Place the order; its value becomes committed cost | Procurement officer | Purchase order | Approval per H-09 | P1-11 |
| 4. Receive the goods at the store or site | Store keeper | Goods receipt | none | P1-11 |
| 5. Value the received stock (weighted average or FIFO) | System | Stock ledger entry | none | P1-13 |
| 6. Receive client-supplied material, tracked by quantity and project only | Store keeper | Client-owned stock receipt | none | P1-12 |
| 7. Issue material to a project | Store keeper | Stock issue | none | P1-12 |
| 8. Match the vendor bill to the order and receipt | Accountant | Vendor bill | Approval per H-09 | P2-05 |
| 9. Pay the vendor | Accountant | Payment voucher | Approval; the creator cannot approve | P2-05 |
