# Workflow: quotation to project

From first enquiry to a running project. Actors are role names; who holds each role is decided in H-10, and approval limits in H-09.

| Step | Actor | Document produced | Approval | Spec |
|---|---|---|---|---|
| 1. Record the enquiry and schedule follow-ups | Office staff | Lead record | none | P1-06 |
| 2. Visit the site and record what was found | Estimator | Site visit note | none | P1-06 |
| 3. Price the job from a template and see internal cost and margin | Estimator | Internal estimate | none | P1-07 |
| 4. Issue a lump-sum quotation with a payment-stage schedule | Estimator | Quotation (PDF) | Margin floor approval (H-09) | P1-08 |
| 5. Client accepts; the accepted quotation is handed to projects | Owner | Accepted quotation | Approval per H-09 | P1-08 |
| 6. Create the project with location, sector, contract value and budget by cost code | Project manager | Project and budget | none | P1-09 |
| 7. Record scope changes found on site and get client approval | Project manager | Variation | Client approval and internal approval (H-09) | P1-10 |
