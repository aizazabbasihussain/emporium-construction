# Workflow: site daily cycle

What a supervisor and the office do on a working day. Supervisors may have weak connectivity, so drafts are saved on the phone and retried.

| Step | Actor | Document produced | Approval | Spec |
|---|---|---|---|---|
| 1. Record attendance for the team, per worker per project | Supervisor | Attendance sheet | none (approved later) | P1-17 |
| 2. File the daily progress report with photos | Supervisor | Daily progress report | none | P1-15 |
| 3. Keep drafts on the phone and retry when the connection returns | Supervisor | Queued draft | none | P1-20 |
| 4. Review the report | Project manager | Reviewed report | Review | P1-15 |
| 5. Claim small site spending with a receipt | Supervisor or custodian | Expense claim | Approval per H-09 | P1-14 |
| 6. Remind about missing reports and pending approvals | System | In-app notification | none | P1-04 |
| 7. See cost, missing reports and labour usage per project | Owner | Operational reports | none | P1-19 |
