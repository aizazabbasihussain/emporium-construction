# Export: Cash and bank book (`cash_bank_book`)

Schema version: 1

Every cash book transaction of each cash and bank account, with the running balance of the account.

## Source

Cash book: transactions of the period, per account (or the account chosen).

## Columns

| Column | Type | Meaning |
| --- | --- | --- |
| fiscal_year | text | Fiscal year label of the row date, for example FY2026-27 (July start) or FY2026 (January start). Label only; nothing is closed. |
| month | text | Month of the row date, yyyy-mm. |
| account | text | Cash or bank account code. |
| date | date | Document or transaction date, yyyy-mm-dd. |
| number | text | Document number. |
| description | text | Description or reference of the transaction. |
| money_in | money | Money in, PKR. |
| money_out | money | Money out, PKR. |
| net | money | Movement of the balance, PKR (see control totals). |
| balance | money | Running balance after the row, PKR. |
| account_code | text | Chart of accounts code of the line. Blank if the line is untagged or is not a document line. |

Types: `text`, `date` (yyyy-mm-dd), `money` (PKR, two decimals), `qty` (four decimals), `int`.

## Order

Account code, date, number.

## Header block and footer

Above the data: report name, filters, period, fiscal year, schema version, generated at (Asia/Karachi), generated by, and the number of untagged lines. Below the data: the row count and a totals row with the sum of every money column.

## Control totals

net (money in less money out) is tied to the change in the account balance reported by the cash book over the period. A difference aborts the run with an error and nothing is stored.

## Files

An Excel file and a CSV file (UTF-8 with a byte order mark). The checksum in the run log covers the data section only (column keys and rows), so the same data gives the same checksum on any day.

## Changes

A change of columns is a new schema version of this file; earlier versions stay reproducible for runs already made.
