# Export: Post-dated cheque register (`pdc_register`)

Schema version: 1

Post-dated cheques received, with status and the date they cleared.

## Source

Receivables: the cheque register for cheque dates in the period.

## Columns

| Column | Type | Meaning |
| --- | --- | --- |
| cheque_no | text | Cheque number, blank if not a cheque. |
| bank | text | Drawer bank. |
| party | text | Client, vendor or subcontractor name. |
| cheque_date | date | Date written on the cheque. |
| status | text | Status in the owning module. |
| cleared_on | date | Date the cheque cleared, blank if not yet. |
| amount | money | Amount, PKR. |
| account_code | text | Chart of accounts code of the line. Blank if the line is untagged or is not a document line. |

Types: `text`, `date` (yyyy-mm-dd), `money` (PKR, two decimals), `qty` (four decimals), `int`.

## Order

Cheque date.

## Header block and footer

Above the data: report name, filters, period, fiscal year, schema version, generated at (Asia/Karachi), generated by, and the number of untagged lines. Below the data: the row count and a totals row with the sum of every money column.

## Control totals

amount is tied to the total of the status totals of the register. A difference aborts the run with an error and nothing is stored.

## Files

An Excel file and a CSV file (UTF-8 with a byte order mark). The checksum in the run log covers the data section only (column keys and rows), so the same data gives the same checksum on any day.

## Changes

A change of columns is a new schema version of this file; earlier versions stay reproducible for runs already made.
